# TOTVS Cert Uploader v1.4.1

- Executável Windows menor, com uso do Google Chrome ou do Microsoft Edge instalado no computador.
- O aplicativo tenta abrir o Chrome primeiro e usa o Edge se o Chrome não abrir.
- As janelas do navegador permanecem visíveis durante a automação.

Use um computador Windows com Google Chrome ou Microsoft Edge e mantenha o arquivo de configuração local junto ao executável.
